# Manifests

(ported from rocq-mcp-evolve's `data/manifests/` layout, restructured for the
single PutnamBench-60 dataset — see `testing/harness/datasets.py`'s module
docstring for the held-out discipline this directory's guard enforces.)

- `smoke2.jsonl` — 2 named putnam60 problems (`putnam_1977_a3`,
  `putnam_1988_b1`), generated by `harness/make_manifests.py`. **UNGUARDED by
  design**: debug-only, never reported as a held-out result (see the
  deviations table in `testing/README.md` — unlike rocq-mcp-evolve, there is
  no separate dev pool to draw a smoke set from).
- `putnam60.jsonl` — the full 60-problem held-out manifest, generated by
  `harness/make_putnam_manifest.py`. **GUARDED**: that script raises
  `RuntimeError("held-out putnam60 split is locked")` unless
  `testing/FINAL_UNLOCK` exists AND `LEAN_FINAL_EVAL=1` (see
  `testing/FROZEN.md`'s held-out procedure). Regenerating it is safe (it is
  pure metadata: `problem_id`, `source`, `difficulty`, `source_tier`,
  `theorem_name`, `path` — derived from `dataset/manifest.json`, no proof
  content) but should only be done once, at the declared start of the final
  run, per the pre-registered protocol.

Record shape (both files): `{problem_id, source, difficulty, source_tier,
theorem_name, path}` — `path` is relative to the repo root (e.g.
`dataset/easy/putnam_1977_a3.lean`).

## medium5_test.jsonl (debug run, 2026-09-06)

5 `medium` problems drawn with `random.Random(42).sample(sorted medium pool, 5)`
for an end-to-end test of the harness with claude-sonnet-5 (1 rep, parallel 1,
config `session_try_hints_auto_sonnet`). Debug only: these attempts touch 5 of
the 60 held-out problems and must not be counted in any registered look.
